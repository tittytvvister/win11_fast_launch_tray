# Win11 Fast Launch Tray

Лёгкий лаунчер для Windows 11: иконка возле часов открывает категоризированное меню ярлыков из обычной папки.

## Возможности

- запуск `.lnk` и `.url` из системного трея;
- категории из папок первого уровня;
- автоматическая светлая/тёмная тема Windows 11;
- PerMonitorV2 DPI awareness и чёткий текст при масштабировании;
- единый размер иконок приложений без shortcut-overlay;
- кастомная tray-иконка;
- закрытие меню кликом вне него;
- автозапуск без прав администратора.

## Быстрый старт

1. Скачайте репозиторий или папку `dist`.
2. Создайте `%USERPROFILE%\Desktop\menu`.
3. Создайте внутри папки категорий, например `Игры`, `Работа` и `VR`.
4. Положите ярлыки в соответствующие папки.
5. Запустите `dist\Install-FastLaunch.cmd`.
6. Если иконка скрыта, раскройте `^` возле часов и перетащите её на панель.

Лаунчер перечитывает папку при каждом открытии меню. Перезапуск после добавления ярлыка не нужен.

## Категории

Каждая папка первого уровня автоматически становится отдельной категорией:

```text
menu/
  Игры/
    Cyberpunk 2077.lnk
  Работа/
    Recordly.lnk
  VR/
    SteamVR.url
```

Новая папка появляется в меню при следующем открытии Fast Launch, даже если она пустая. Для пустой категории отображается неактивный пункт «Папка пуста». Ярлыки в корне `menu` не показываются: переместите их в нужную категорию. Вложенные подпапки внутри категории сканируются рекурсивно.

## Конфигурация

Основные поля `config/fast-launch-config.json`:

- `sourcePath` — папка ярлыков; поддерживаются переменные окружения, например `%USERPROFILE%`;
- `trayIconPath` — относительный или абсолютный путь к `.ico`;
- `categoryOrder` — порядок категорий;

Папки, которых нет в `categoryOrder`, добавляются после перечисленных категорий по алфавиту.

После установки рабочая копия находится в `%LOCALAPPDATA%\FastLaunch`. Изменения исходного конфига попадают туда при повторном запуске установщика.

## Управление

- повторный запуск после выхода: `dist\Start-FastLaunch.cmd` или `Fast Launch` в меню «Пуск»;
- обновление сборки: `dist\Install-FastLaunch.cmd`;
- полное удаление: `dist\Uninstall-FastLaunch.cmd`.

Удаление не затрагивает папку с пользовательскими ярлыками.

## Сборка

Требуется Windows с установленным .NET Framework 4.x:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Скрипт компилирует приложение через системный `csc.exe`, генерирует иконку и пересобирает `dist`.

## Структура

```text
src/       исходный код и DPI manifest
tools/     генератор tray-иконки
config/    исходная конфигурация
scripts/   установка, запуск и удаление
dist/      готовая переносимая сборка
```
